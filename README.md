# nhv-assets

Assets estáticos servidos por GitHub Pages para uso no checkout da NHV
(seguro.newhair.com.br), onde só há campo de CSS e não é possível
subir arquivo pelo painel.

## checkout/

| arquivo | uso | dimensões |
| --- | --- | --- |
| `danielle-winits-nhv-wide.jpg` | card da embaixadora, **desktop** | 1440x900 (1.6:1) |
| `danielle-winits-nhv.jpg` | card da embaixadora, **mobile** | 460x460 (quadrado) |

Servido em `https://boiamatheus.github.io/nhv-assets/checkout/<arquivo>`

Duas versões de propósito: no desktop a foto fica ao lado do texto e
precisa ser horizontal; no mobile ela ocupa a largura toda e o quadrado
enquadra melhor.

Preferir Shopify > Conteúdo > Arquivos quando houver acesso ao admin.
Este repo é a alternativa para quando não houver.
